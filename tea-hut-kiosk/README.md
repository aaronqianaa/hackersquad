# Tea Hut Kiosk

Self-order kiosk for Tea Hut stores. Android touchscreen smart TV, Square as the backend of
record for menu, orders, and payments. Internal use only.

**Nothing is built yet.** This folder currently holds the plan for review:

- [`PLAN.md`](./PLAN.md) — architecture, full feature list, open questions, phasing.

Start with §0 of the plan — three decisions there shape everything else, in particular the fact
that Square prohibits card entry on the kiosk device itself, so payments run through a paired
Square Terminal.
